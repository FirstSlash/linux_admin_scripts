# Linux Admin Scripts

Набор практических Bash-скриптов для базовой диагностики сети, системных ресурсов и проверки окружения сервисов в Linux.

## Состав репозитория

* **`ping_servers.sh`** — пакетная проверка сетевой доступности списка узлов (`8.8.8.8`, `1.1.1.1`, `127.0.0.1`) в цикле с анализом кода возврата ICMP-запросов.
* **`syshealth.sh`** — мониторинг доступной оперативной памяти и свободного места на дисковых разделах.
* **`check_service.sh`** — проверка наличия и доступности лог-файлов службы в `/var/log/` с валидацией входных аргументов.

## Примеры использования

Клонирование репозитория и выдача прав на выполнение:

```bash
git clone https://github.com
cd linux-admin-scripts
chmod +x *.sh
```

Проверка доступности серверов:
```bash
./ping_servers.sh
```

Проверка наличия лог-файла конкретного сервиса (например, `nginx`):
```bash
./check_service.sh nginx
```

## Стек и инструменты
* **OS:** Arch Linux / Debian / Ubuntu
* **Утилиты:** Bash, awk, systemd, ping
